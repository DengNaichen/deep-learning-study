## Labs 优先级

### 必须完成

- L0 C Programming Lab
- L1 Data Lab 核心题目
- L2 Bomb Lab 主要阶段
- L4 Cache Lab 基础部分

### 有余力再完成

- L3 Attack Lab
- L1/L2 的额外题目
- L4 Cache Lab 的优化部分

## 月末检查

- 能独立编译、运行和调试 C 程序；
- 能解释指针、数组、栈、寄存器和函数调用；
- 能解释补码、位运算和整数溢出；
- 能使用 GDB 和 `objdump` 阅读简单汇编；
- 能解释 Cache 的基本组织和命中率；
- 能独立运行并测试本月完成的 Labs。
